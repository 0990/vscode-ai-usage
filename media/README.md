# Status-bar artwork

- `claude.svg` is the Claude starburst mark, obtained from [Lobe Icons](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/claude.svg). Its 24-unit artwork is rendered at 14 × 14px, centered in the native 16px status-bar glyph cell (approved option B). The glyph inherits the current VS Code theme's foreground color. See `openai-LICENSE.txt` for the shared source package license.
- `openai.svg` is the monochrome OpenAI knot mark, obtained from [Lobe Icons](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/openai.svg). See `openai-LICENSE.txt` for the source package license.
- `ai-usage-icons.woff` contains the native theme-aware status-bar glyphs built by `scripts/build-icons.py`.
